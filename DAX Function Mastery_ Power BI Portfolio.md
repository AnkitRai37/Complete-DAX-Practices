# DAX Function Mastery: Power BI Portfolio

## Project Overview

This repository showcases a comprehensive practice and application of Data Analysis Expressions (DAX) within Microsoft Power BI. The accompanying `.pbix` file, `DAXFunctionReports(1).pbix`, serves as a portfolio demonstrating proficiency in DAX, ranging from fundamental concepts to advanced analytical techniques. This project aims to provide a clear understanding of how DAX functions can be leveraged to create dynamic, insightful, and interactive business intelligence reports.

## Features

*   **Extensive DAX Practice**: Implementation of a wide array of DAX functions, including aggregation, filtering, time intelligence, and conditional logic.
*   **Interactive Power BI Reports**: Multiple report pages designed to visualize key business metrics and demonstrate DAX capabilities.
*   **Structured Learning**: Organized practice covering basic, intermediate, and advanced DAX concepts.
*   **Clear Documentation**: This README, along with the detailed PDF report, provides in-depth explanations of the DAX measures and their applications.

## DAX Concepts Covered

This project delves into various DAX concepts, including but not limited to:

### Fundamentals
*   **Basic Aggregation**: `SUM()`, `AVERAGE()`, `COUNT()`, `MIN()`, `MAX()`
*   **Calculated Columns vs. Measures**: Understanding their distinct uses and implementation.
*   **Context Transition**: Grasping the core concept of row context converting to filter context.

### Intermediate Concepts
*   **`CALCULATE()`**: The most powerful DAX function for modifying filter context.
*   **Filter Functions**: `ALL()`, `ALLEXCEPT()`, `FILTER()` for precise data manipulation.
*   **Time Intelligence**: `TOTALYTD()`, `SAMEPERIODLASTYEAR()`, `DATEADD()` for temporal analysis.

### Advanced Applications
*   **Iterator Functions**: `SUMX()`, `AVERAGEX()` for row-level calculations within aggregations.
*   **KPIs and Conditional Logic**: Implementing `IF()`, `SWITCH()` for performance indicators and dynamic reporting.

## Report Pages

The `DAXFunctionReports(1).pbix` file contains the following report pages, each designed to illustrate specific DAX applications:

*   **Sales Overview Dashboard**: High-level summary of sales performance.
*   **Profitability Analysis**: Detailed breakdown of profit by various dimensions.
*   **Sales Trend Dashboard**: Visualization of sales performance over time using time intelligence.
*   **Finance KPI Dashboard**: Key financial indicators and their performance.
*   **Target vs Achievement Dashboard**: Comparison of actual performance against set targets.
*   **Advance Filtering**: Demonstrates advanced filtering techniques.
*   **Row Wise Analysis**: Examples of row-level calculations.

## How to Use

1.  **Clone the Repository**: 
    ```bash
    git clone https://github.com/your-username/DAX-Function-Mastery.git
    ```
2.  **Open in Power BI Desktop**: Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/). Open the `DAXFunctionReports(1).pbix` file with Power BI Desktop.
3.  **Explore the Reports**: Navigate through the different report pages to see the DAX measures in action.
4.  **Inspect DAX Formulas**: In Power BI Desktop, go to the 
    **Model View** or **Data View** to inspect the DAX formulas used for measures and calculated columns.
